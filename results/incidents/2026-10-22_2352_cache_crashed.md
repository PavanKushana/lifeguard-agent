## Root cause

Redis 7.4 has a known segfault (signal 11) that crashes the cache container, removing the session store and breaking login/cart.

Confidence: high. Evidence:
- cache Exited (139) 25 min ago
- logs show "Redis 7.4.0 crashed by signal: 11"
- upgrade from 7.2 to 7.4 9 days ago
- GitHub issue #12441 confirms bug

## Fix

**Restart Redis 7.4 (temporary)**

1. `restart(container=cache)`

How to undo: none needed

What was done:
- restarted cache

Options that were offered:
- Restart Redis 7.4 (temporary) (approved)
- BLOCKED by the safety check: Rollback to Redis 7.2 (step 1: cache holds data and has run redis:7.4 for 9 days; its data files are in that version's format, and redis:7.2 may not be able to read them. Only an upgrade from the last day can be rolled back)
