## Root cause

The Redis cache container crashed with a segmentation fault (signal 11) after being upgraded from Redis 7.2 to 7.4, causing the API to lose its session store connection and return 500 errors for login and cart operations.

Confidence: high. Evidence:
- Cache container status shows Exited (139) 25 minutes ago (list_containers).
- Cache logs contain a Redis bug report: "Redis 7.4.0 crashed by signal: 11" at 2026-10-22 23:19:03 (get_logs cache).
- API logs show errors starting at 23:20:03: "Error 111 connecting to cache:6379. Connection refused." for login and cart endpoints (get_logs api).
- Recent changes confirm cache was upgraded from redis 7.2 to 7.4 nine days ago (recent_changes).

## Fix

**Rollback cache to Redis 7.2**

1. `rollback(container=cache, to_image=redis:7.2)`

How to undo: Rollback cache container to redis:7.4 again.
