## Root cause

API container crashes on startup due to missing pydantic_settings dependency introduced in deploy 2.3.2, causing a restart loop (14 restarts) and leaving nginx with no healthy backend, resulting in 502 errors.

Confidence: high. Evidence:
- API logs show repeated ModuleNotFoundError: No module named 'pydantic_settings' at 2026-10-22 23:21:11
- Recent changes show deploy of api 2.3.2 'settings moved to pydantic-settings' 21 minutes ago
- Container status: api is 'Restarting (1) 1 minute ago' with 14 restarts
- Endpoint check returns HTTP 502
