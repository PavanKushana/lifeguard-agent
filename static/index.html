    How it works

    From the first complaint to a checked fix

    Three NVIDIA Nemotron models share the work like an on-call team. Our own code checks every step, and you make the final call.

    1. Alert

      The complaint

      Customers report what they see. That's all the agent gets, never the answer.

    2. Nano

      First look

      Reads the complaint and decides where to look first.

    3. Super

      Investigates

      Runs read-only tools on logs, disks, jobs and recent changes, and searches the web.

    4. Ultra

      Final call

      Checks the evidence, names the root cause and suggests up to 3 fixes.

    5. You

      You approve

      Our code blocks risky steps. Nothing runs without your OK, here or in Telegram.

    6. Checked

      Proven fixed

      Confirms customers can use the shop again, then writes the postmortem.

    Safety

    Built so it can't make things worse

    The AI suggests, our code checks, and a person decides. Nothing runs without all three.

    It can only look

    Every investigation tool is read-only: container status, logs, disk use, jobs and health checks.

    A short menu of fixes

    Roll back, restart, change a memory limit, move files or turn off a job. Deleting isn't on the menu.

    Checked twice

    Our code checks every fix step before you see it, and again the moment you approve.

    Proof, not promises

    After a fix it checks that the customers' own action works again, and shows you the log lines.

    Alerts on your phone

    Link Telegram once. When the shop breaks, you get the cause and the fixes, and approve with two taps.

    Your own problems too

    Describe any problem in your own words. The agent has to find it like a real one.
