Lifeguard

When the shop goes down at 3 a.m.,
Lifeguard finds out why.

It does what an on-call engineer would do: reads the logs, checks the disks, looks at what changed, and searches the web for errors it doesn't know. Then it tells you what went wrong and how to fix it. Nothing changes until you say yes.

Try it on the demo shop below. Break something on purpose and watch.

Runs on NVIDIA Nemotron 3 (Nano, Super and Ultra) through Nebius Token Factory, with Tavily for web search.
